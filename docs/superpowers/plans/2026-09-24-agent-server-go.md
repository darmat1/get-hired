# Agent Server in Go — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Execution in this project:** each task is handed to Antigravity CLI (`agy -p … --mode accept-edits`) as a self-contained prompt; the Opus session reviews `git diff` after each task. Per the user's instruction to save Claude limits, porting steps name the exact TS source to port and the traps to avoid instead of pre-writing every Go line; tests, interfaces, fixtures and commands are given in full.

**Goal:** Turn `mcp-gateway/` from a proxy into a full agent API server (MCP + REST `/api/agent/v1/*`) that talks to Postgres and AI providers directly, so agent traffic stops costing Vercel CPU.

**Architecture:** One Go binary, packages under `mcp-gateway/internal/`: `config`, `db`, `auth`, `ai`, `prompts`, `store`, `gen`, `rest`, `mcp`. `rest` and `mcp` are thin layers over `store` + `gen`. PDF stays in Next and is proxied. Next gets an edge rewrite `/api/agent/*` → `agents.gethired.work` and loses its agent routes (except PDF).

**Tech Stack:** Go 1.25, `github.com/mark3labs/mcp-go` v1.0.0 (already used), `github.com/jackc/pgx/v5`, `github.com/lucsky/cuid`, `github.com/toon-format/toon-go`, stdlib `net/http`, `crypto/aes`, `crypto/cipher`. Golden fixtures generated by vitest from the TS code.

**Spec:** `docs/superpowers/specs/2026-09-24-agent-server-go-design.md`

- Run the commands in the task and include their output in your final report.

## Database traps (every task touching SQL)

- Prisma models without `@@map` use the **quoted model name** as table name: `"Resume"`. Mapped ones: `"user"`, `agent_token`, `agent_request_event`, `ai_usage_event`, `user_ai_key`, `cover_letter`, `user_profile`.
- Columns have no `@map`, so they are **camelCase and must be quoted**: `"userId"`, `"tokenHash"`, `"updatedAt"`, …
- `@default(cuid())` is generated client-side by Prisma → Go must generate ids with `cuid.New()`.
- `@updatedAt` is client-side → Go must set `"updatedAt" = now()` on every insert and update.
- `createdAt @default(now())` has a real DB default — omit it on insert.
- `Json?` columns are `jsonb`. `String[]` (scopes) is `text[]`.
- Supabase pooler on port 6543 is pgbouncer transaction mode → pgx must use `QueryExecModeSimpleProtocol` (no prepared statement cache).

```go
package config

import (
	"errors"
	"os"
	"strings"
)

type Config struct {
	Port           string
	DatabaseURL    string
	EncryptionKey  string // 64 hex chars; may be empty (user keys then unusable)
	BaseURL        string // Next deployment, used for PDF proxy
	AgentsDisabled bool
	ProviderOrder  []string // AI_PROVIDER_ORDER, empty = registry order
	ProviderKeys   map[string]string
}

func Load() (Config, error) {
	c := Config{
		Port:           getenv("PORT", "8080"),
		DatabaseURL:    os.Getenv("DATABASE_URL"),
		EncryptionKey:  os.Getenv("ENCRYPTION_KEY"),
		BaseURL:        strings.TrimRight(getenv("GETHIRED_BASE_URL", "https://gethired.work"), "/"),
		AgentsDisabled: os.Getenv("AGENTS_DISABLED") == "1" || os.Getenv("AGENTS_DISABLED") == "true",
		ProviderKeys:   map[string]string{},
	}
	if c.DatabaseURL == "" {
		return c, errors.New("DATABASE_URL is required")
	}
	for _, id := range strings.Split(os.Getenv("AI_PROVIDER_ORDER"), ",") {
		if id = strings.TrimSpace(id); id != "" {
			c.ProviderOrder = append(c.ProviderOrder, id)
		}
	}
	return c, nil
}

func getenv(k, def string) string {
	if v := os.Getenv(k); v != "" {
		return v
	}
	return def
}
```

// db.go
package db

import (
	"context"

	"github.com/jackc/pgx/v5"
	"github.com/jackc/pgx/v5/pgxpool"
)

// Open creates a pool safe for Supabase's transaction-mode pooler (port 6543):
// no prepared statement cache.
func Open(ctx context.Context, url string) (*pgxpool.Pool, error) {
	cfg, err := pgxpool.ParseConfig(url)
	if err != nil {
		return nil, err
	}
	cfg.ConnConfig.DefaultQueryExecMode = pgx.QueryExecModeSimpleProtocol
	cfg.MaxConns = 5
	return pgxpool.NewWithConfig(ctx, cfg)
}
```

package auth

type Scope string

const (
	ProfileRead       Scope = "profile:read"
	ProfileWrite      Scope = "profile:write"
	ResumesRead       Scope = "resumes:read"
	ResumesWrite      Scope = "resumes:write"
	CoverLettersRead  Scope = "cover_letters:read"
	CoverLettersWrite Scope = "cover_letters:write"
	AIGenerate        Scope = "ai:generate"
)

type Context struct {
	TokenID string
	UserID  string
	Scopes  []Scope
}

func HashToken(token string) string                     // sha256 hex
func (c *Context) Has(s Scope) bool
// Authenticate reads "Authorization: Bearer agt_…", returns nil (no error) when
// the token is missing/unknown/revoked/expired — same as TS returning null.
// On success: updates lastUsedAt if older than 5 min (fire-and-forget like TS),
// inserts agent_request_event{tokenId,userId,transport,route}.
func Authenticate(ctx context.Context, pool *pgxpool.Pool, authHeader, transport, route string) (*Context, error)
```

Match TS behavior exactly for: prefix check, which errors are swallowed, the 5-minute throttle, and whether the event insert is awaited. Transport is `"mcp"` or `"rest"`; route is the request URL path (TS logs `url.pathname`).
